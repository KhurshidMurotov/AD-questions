HOW TO READ .md FILES

The companion guides are in Markdown (.md) format. To read them properly:

OPTION 1 (RECOMMENDED): OBSIDIAN
- Download: https://obsidian.md
- Install, open it, click "Open folder as vault", pick any folder
- Drag the .md files into that folder
- Click on the file — done, rendered beautifully

OPTION 2: VS CODE
- Download: https://code.visualstudio.com
- Open the .md file
- Press Ctrl+Shift+V to see the rendered preview
- Works fine, just not as pretty

Do NOT open .md files in Notepad or Word — you'll see raw formatting symbols instead of the actual content.
